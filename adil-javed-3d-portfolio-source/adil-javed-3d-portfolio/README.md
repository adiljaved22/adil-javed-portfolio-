# Adil Javed — Interactive Digital World

A responsive React + Vite portfolio with a Three.js / React Three Fiber interactive world, services, project showcase, QA sample downloads, 15 transcribed client reviews, social links and WhatsApp contact.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create the production site in `dist/`.
