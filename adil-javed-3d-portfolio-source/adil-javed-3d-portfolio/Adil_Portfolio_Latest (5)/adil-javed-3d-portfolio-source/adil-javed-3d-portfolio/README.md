# Adil Javed — Interactive 3D Digital World

A responsive React + Vite portfolio with a Three.js / React Three Fiber island world, keyboard-driven explorer pod, clickable portfolio zones, services, selected work, QA report downloads, 15 client-review excerpts, and contact links.

## Run locally
1. Install Node.js 18 or newer.
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. Run `npm run build` to create the production site in `dist/`.

## Interactive world
- Use **W / A / S / D** or the arrow keys to move the small explorer pod.
- Drag to orbit the world and use the mouse wheel to zoom.
- Click a labelled island or use the zone links to open its portfolio section.
